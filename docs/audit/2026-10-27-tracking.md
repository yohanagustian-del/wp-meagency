Hanya baca. Tidak ada yang diubah di situs live.

**Batasan audit ini.** HTML publik tidak bisa diambil dari lingkungan kerja audit: proxy
menolak `www.meagency.co.id`. Karena itu sumber tracking di bawah dibaca dari **konfigurasi**
lewat konektor WordPress (Code Snippets, WPCode, Site Kit, Rank Math, daftar plugin) dan dari

`tools/tracking-audit/audit.sh` dari komputer tim:

```sh
sh tools/tracking-audit/audit.sh > audit-tracking.md
```

Assistant / GTM Preview (bagian 4).

## 3. noindex halaman berpassword

- Laporan berpassword (contoh 35298 `/urung-bantal-weekly-report-19-25-okt/`): Rank Math
  mengeluarkan `noindex, follow`. Asalnya dari **Rank Math**, bukan WPCode (WPCode tidak punya
  snippet aktif). Kemungkinan besar dari pengaturan global Rank Math untuk halaman berpassword;
  cek di Rank Math → Titles & Meta.
- **Temuan penting:** laporan **35317 `/dapur-roca-shop-shopee-weekly-report-19-25-okt/` tidak
  berpassword** dan berstatus `index, follow`. Ringkasan GMV, jumlah pesanan, dan ROAS klien
  ikut tampil di og:description. Laporan ini terbuka untuk umum dan bisa diindeks Google.
  Perlu dipasang password (Visibilitas → Dilindungi sandi), lalu cek ulang laporan lain yang
  dibuat dengan cara yang sama.

## 4. Rekomendasi

**Satu plugin snippet: Code Snippets.** WPCode Lite tidak punya snippet aktif.

1. Buka WPCode → Code Snippets → **Header & Footer**. Bila ketiga kotak kosong, nonaktifkan
   WPCode Lite. Bila masih ada isi yang dipakai, pindahkan dulu ke Code Snippets (fitur Import
   Code Snippets bisa membaca WPCode) atau ke GTM.
2. **#9 (pengaturan pixel):** pengaturan yang ditulisnya sudah tersimpan di database, jadi
   snippet ini tidak perlu jalan di setiap request. Setelah memastikan halaman pengaturan
   plugin Meta menampilkan pixel 1133774585771727 dan CAPI terhubung, nonaktifkan #9. Bagian
   `tt4b_*` tidak berpengaruh (plugin TikTok tidak terpasang).
   **Token akses Meta CAPI dan TikTok Events API tersimpan sebagai teks biasa di dalam snippet
   ini**, sehingga bisa dibaca siapa saja yang punya akses admin atau REST Code Snippets.
   Sarannya: buat token baru di Meta Events Manager dan TikTok Events Manager, simpan hanya di
   pengaturan plugin, lalu hapus snippet #9.
3. **#11 (TikTok Pixel):** pindahkan ke GTM (template tag TikTok Pixel, trigger All Pages) dan
   nonaktifkan #11, supaya pixel browser dikelola di satu tempat.
4. **#12 (redirect 301):** pindahkan ke Rank Math → Redirections (satu tempat untuk semua
   redirect, ada penghitung hit), lalu nonaktifkan #12.
5. **#10 dan contoh 1–8:** boleh dihapus setelah langkah 1 selesai.

**Pixel lewat GTM saja?** Sebagian.

- **Meta tetap di plugin Meta.** Plugin mengirim pixel browser dan Conversions API dengan
  deduplikasi event otomatis. Memindahkan pixel browser ke GTM sambil CAPI tetap di plugin
  membutuhkan `event_id` yang sama di kedua sisi; tanpa itu konversi terhitung dobel.
- **TikTok browser pixel → GTM** (rekomendasi 3).
- **GA4: pilih satu.** Tetap di Site Kit (paling sederhana) dan pastikan GTM tidak punya tag
  GA4 yang sama, atau pindahkan ke GTM dan matikan snippet Analytics Site Kit.
- **Konversi lead di GTM.** Event `generate_lead` dari form (`form_source`, `lead_omzet`) dipakai
  sebagai trigger untuk GA4 `generate_lead`, Meta `Lead`, dan TikTok `SubmitForm`.

Urutan aman: ubah satu sumber, cek dengan Tag Assistant / Pixel Helper, baru lanjut ke sumber
berikutnya.
